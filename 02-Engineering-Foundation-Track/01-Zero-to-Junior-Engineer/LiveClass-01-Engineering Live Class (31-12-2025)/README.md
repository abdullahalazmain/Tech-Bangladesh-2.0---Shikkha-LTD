# HTML Elements Deep Dive: Images and Lists
### Zero to Junior Engineer
Live Class: 01 | Date: 31 December 2025

## Learning Topics
* **image tag (img):** ওয়েবসাইটের ইমেজ ম্যানেজমেন্ট।
* **Attributes (src, alt, width, height):** ইমেজের সোর্স, অল্টারনেটিভ টেক্সট এবং সাইজ কন্ট্রোল।
* **Image Path:** লোকাল ফাইল এবং অনলাইন লিঙ্কের মাধ্যমে ইমেজ কানেক্ট করা।
* **Unit Comparison:** পিক্সেল (px) এবং পার্সেন্টেজ (%) এর মধ্যে পার্থক্য।
* **Lists (ul, ol, li):** আন-অর্ডারড এবং অর্ডারড লিস্টের ব্যবহার।
* **List Customization:** `type`, `start` এবং `none` ভ্যালু ব্যবহার করে লিস্ট স্টাইল করা।
* **Formatting & Helpers:** লেখাকে বোল্ড করা এবং 'Lorem Ipsum' ডামি টেক্সটের প্রয়োজনীয়তা।

## Technical Terms
* Attribute
* File Path (Relative/Absolute)
* SEO (for alt tag)
* Live Preview Extension
* Dummy Text

## Overview
এই ক্লাস থেকে আমি শিখেছি কীভাবে একটি ওয়েব পেজে ছবি যুক্ত করতে হয় এবং ছবির পাথ সঠিকভাবে ডিফাইন করতে হয়। এছাড়া বিভিন্ন ধরণের লিস্ট তৈরি এবং অ্যাট্রিবিউট ব্যবহারের মাধ্যমে সেগুলোকে নিয়ন্ত্রণ করার নিয়মগুলো আয়ত্ত করেছি।

| Topic Name | Description | Usage/Unit |
| :--- | :--- | :--- |
| `<img>` | Image rendering tag | Web page visuals |
| `src` | Image location source | URL or File Path |
| `alt` | Backup description | Text |
| `width/height` | Sizing of elements | px, % |
| `<ul>` | Unordered collection | Bullet points |
| `<ol>` | Ordered collection | Numbers/Letters |
| `start` | Starting point of list | Number |
| `<b>` | Bold text | Visual emphasis |

## Practice Task

* লোকাল ও অনলাইন ইমেজের সঠিক পাথ ব্যবহার করে ইমেজের গ্যালারি তৈরি।
* বিভিন্ন `type` অ্যাট্রিবিউট ব্যবহার করে রোমান সংখ্যা এবং লেটার লিস্ট তৈরি করা।
